# Security

This package stores imported FTN archive facts. Most issues will be schema or import-edge bugs, but reports still need a clean path.

## Supported Versions

| Version | Supported |
| --- | --- |
| `1.x` | Yes |

## Reporting A Vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub Security Advisories for this repository:

https://github.com/golded-dev/laravel-ftn-database/security/advisories/new

Include:

- what is affected
- how to reproduce it
- what impact you expect
- whether you have a suggested fix

If the report is valid, the fix will ship with a patched release and a changelog entry.
